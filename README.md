# ProxView

Sistem Pemantauan Terpusat Infrastruktur Proxmox VE & Jaringan (ICMP / TCP) Dinas Komunikasi dan Informatika Kabupaten Subang.

## Gambaran Umum
ProxView menyediakan pemantauan metrik server Proxmox VE (Node, VM, LXC Container, Storage), status konektivitas jaringan, pelacakan riwayat insiden dan SLA secara *real-time*, notifikasi darurat (Push Notification & VoIP CallKit), serta utilitas diagnosa jaringan (Ping, Traceroute, IP Scan).
